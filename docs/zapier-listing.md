## Description

Screpy is an SEO analysis and monitoring platform for website audits, search visibility, performance, and uptime.

## Authentication help

Sign in to Screpy and open **Settings > Connected Apps**. Create a REST API key, then paste it into Zapier. A read-only key supports triggers, searches, and read actions. Create, update, delete, and crawl-start actions require a read-and-write key.

## Component copy

The component names and descriptions are defined in `src/operations` and `src/triggers`. Before submission, confirm that every visible label and help text in the Zap Editor matches the current source and remains in English.

## Logo verification

`assets/screpy.png` is a square 512×512 PNG with transparency. Upload it through the Zapier Platform UI; branding is managed separately from CLI code deployments.
