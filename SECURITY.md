# Security Policy

## Supported versions

Security fixes are applied to the latest active integration version.

## Reporting a vulnerability

Do not open a public GitHub issue for a vulnerability or suspected credential exposure.

Report the issue privately through [Screpy Support](https://support.screpy.com/) and include:

- The affected integration version.
- The trigger, search, or action involved.
- Reproduction steps.
- The expected and observed behavior.
- Any evidence with secrets removed.

Never include Screpy API keys, Zapier deploy keys, session tokens, or test-account passwords in a report.
